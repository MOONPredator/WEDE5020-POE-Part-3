# UrbanGear - WEDE5020 POE Part 3

## Project Overview
UrbanGear is a sports & lifestyle e-commerce showcase for Pretoria, SA. Part 3 enhances functionality and SEO.

## Part 3 Enhancements
- **JS Interactive**: Accordions, Tabs, Modals, Lightbox Gallery, Leaflet Map, Fade-in animations
- **Dynamic Content**: productsData array + renderProducts(), search, sort, filter
- **SEO**: Title, meta description, keywords, canonical, OG tags, H1-H3, alt text, sitemap, robots, JSON-LD LocalBusiness, mobile-friendly, lazy loading
- **Forms**: Two distinct forms with HTML5 + JS validation, error handling, AJAX simulation, email compilation with mailto, sanitization for security
- **Performance**: defer JS, lazy images, minified CSS
